The test flow

Select a step to see what happens. Switch modes to compare the two test paths.

1. Create and format a fresh disk

Create a disposable virtual disk in the chosen folder, attach it as a verified loop device, then format and mount it with the selected filesystem.

Full mode measures the first copy, then repeats the dataset to discover usable capacity.

Storage efficiency

How much space the same dataset consumes, including filesystem overhead and compression savings.

Usable capacity

How much logical data fits when the dataset is repeated until available space or a configured limit is reached.

Optional verification checks that copied files match the originals. After each configuration, the disk is removed and results are added to the HTML and JSON reports.

What the measured values mean

The capacity table describes the final fill. The efficiency table compares the same first copy across configurations. Detailed snapshots are recorded when the filesystem is empty, after that first copy, and after filling.

Read the results in context. Capacity depends on the workload. Metadata overhead is estimated, and reserved free space is reported separately. Some counters overlap and should not be added together.

A logical-data limit gives a lower bound on capacity. A dash means a value is unavailable or does not apply. Tool versions, commands, warnings and errors provide context for the measurements.
